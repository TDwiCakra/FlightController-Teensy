🛩️ Teensy 4.0 Flight Controller PCB

📌 Overview This project is a custom PCB design for a flight control system based on the Teensy 4.0. It integrates motor control (ESC), servo outputs, and an IMU sensor for stabilization.

⚙️ Features Teensy 4.0 as main controller 6x ESC (40A) PWM outputs for brushless motors 4x Servo control outputs MPU6050 (I2C) for motion sensing UBEC 5V power input Optional 3.3V regulation for sensors

🔌 Pin Configuration ESC Outputs (PWM) ESC1 → Pin 0 
ESC2 → Pin 1 
ESC3 → Pin 2 
ESC4 → Pin 3 
ESC5 → Pin 4 
ESC6 → Pin 5

Servo S1 → Pin 6 
S2 → Pin 7 
S3 → Pin 8 
S4 → Pin 9

IMU MPU6050 1 
SDA → Pin A4 
SCL → Pin A5

IMU MPU6050 2 
SDA → Pin A3 
SCL → Pin A2
